# dverka.sk — архив работы над сайтом-визиткой

Дамп сессии от 15–16 сентября 2026. Здесь вся история поиска стиля, решения, ссылки на прототипы
и планы. Файл нужен, чтобы продолжить работу с другого компьютера.

---

## 1. Задача

Есть домен **dverka.sk**. Нужен сайт-визитка. Требования, как их формулировал владелец:

- должно быть **уютно и приятно находиться**, отсюда ориентир на игры, в которых ему комфортно:
  **CS 1.6** и **The Binding of Isaac**;
- нужны **запоминающиеся персонажи**, которых можно переодевать (например, в новогоднее);
- из уютного пространства должны быть **переходы на проекты**;
- **уникальность**: не шаблонный лендинг;
- по центру сцены — **ник DverkaSK**, по нему бегает и прыгает **маскот Дверка**
  (маленькая дверь на ножках, шустрая);
- при наведении на Дверку она останавливается и **приоткрывается**, внутри темнота — задел
  на будущий вход «внутрь дверки» (пока не делаем);
- камера стоит на месте, **ходить по сцене не надо**, персонажи просто сидят и тусят.

Про владельца (из README этого репозитория): Java-бэкендер, Kafka / Kubernetes / ClickHouse,
плагины для Minecraft (SpigotMC, Modrinth), с 2026 активно пишет код с ИИ.

### Важный разговор про пределы

Владелец показал **живописную иллюстрацию** (двачер в халате с пакетом на голове, кот-сфинкс,
зимнее окно) и спросил, можно ли так. Ответ: **кодом такую живопись получить нельзя**,
инструмента для рисования картинок в той сессии не было. Уровень Айзека — тоже ручная работа
художника. Честный путь, если нужен такой арт: сгенерировать нейросетью или заказать художнику,
нарезать на слои, а код уже оживляет сцену (параллакс, снег, пар, анимации, маскот, переходы).

Стиль Масяни оказался тем, что кодом действительно достижимо: плоский вектор, контуры, заливка.

## 3. Твёрдые решения

**Делать:**

- сцена-застолье (3D или 2D), камера на месте, персонажи сидят и тусят;
- ник DverkaSK в центре, по нему прыгает Дверка;
- наведение на Дверку: останавливается, машет, приоткрывается в темноту;
- вайб: хрущёвка, ковёр на стене, обои в цветочек, плафон, бумажные фонарики, ёлка,
  кастрюля (тазик) оливье, селёдка под шубой, мандарины, шампанское;
- шрифт **Press Start 2P** владельцу «безумно нравится» (использован в пиксельных версиях).

**Не делать:**

- никакой играбельной копии CS 1.6, никакой беготни, никакого игрового HUD с радаром —
  CS нужен только как вайб;
- не возвращаться к отвергнутым концептам (меню CS, комната Айзека, улочка дверок);
- сезоны и сложную логику пока не трогаем;
- не перерисовывать мемы «по мотивам»: нужен настоящий троллфейс.

## 4. Персонажи

- **Кот** — обязателен. В колпаке, машет хвостом, косится на селёдку.
- **Двачер** — халат, тапки, волосатые ноги, крафтовый пакет на голове с прорезями, кружка.
- **Троллфейсер** — настоящий троллфейс как маска на лице.
- **Крик (Ghostface)** — чёрный балахон, белая маска, нож, режет оливье.
- Никаких женских персонажей и бабушек: только аноны.

**Троллфейс:** используется оригинальный PNG с Википедии, файл лежит в `concepts/src/trollface.png`
(222×180). У картинки белый непрозрачный фон, поэтому в коде он вырезается заливкой от краёв
(flood fill), см. `src/mult/b-chars.js` и `src/cs/1-tex.js`.

**Права:** троллфейс принадлежит Carlos Ramirez (Whynne), и он свои права отстаивает; маска Крика —
товарный знак Fun World; текстуры из halflife.wad и cstrike.wad принадлежат Valve. Владелец сказал,
что юридические риски берёт на себя.

## 7. Технические заметки по прототипам

Каждый прототип — один самодостаточный HTML-файл, картинки вшиты как data URI. Открывается
двойным кликом, но тем, где используется Three.js, нужен интернет (CDN). Прототипы 5 и 8
работают полностью без сети.

- **№ 1, 2** — чистый Canvas 2D. В № 1 есть мини-рейкастер в духе Wolfenstein
  (шаблоны этих двух лежали в scratchpad, в архив попали только готовые HTML).
- **№ 3** (`src/street/`) — SVG-сцена, слои с параллаксом, гардероб в localStorage.
  Сборка: `python build.py` (вшивает иконки из `icons/`).
- **№ 4** (`src/flat/`) — Three.js r128 с CDN, низкое разрешение рендера, дизеринг-шейдер,
  переключатели «стиль» и «пиксель». Сборка: `python patch.py && python build.py`.
- **№ 5** (`src/px/`) — рукописный пиксель-арт 384×216, целочисленный масштаб, дизеринг-свет,
  лица рисуются поверх света без ряби. Сборка: склейка `a-raster.js b-scene.js c-mascot.js d-main.js`
  под `head.html`.
- **№ 6** (`src/cs/`) — Three.js, низкополигональные персонажи, мыльные текстуры (LinearFilter),
  арка во вторую комнату с телевизором. Сборка: `python build.py`
  (берёт маскота из `src/flat/3-mascot.js`).
- **№ 7** (`src/syc/`) — Three.js плюс модули из examples/js: RoundedBoxGeometry, RoomEnvironment,
  RectAreaLight, EffectComposer, UnrealBloomPass. Экран монитора — настоящий источник света,
  своя постобработка: ACES, гамма, виньетка, зерно, хроматическая аберрация.
  Сборка: `python build.py`. Для локального просмотра нужны файлы библиотек в `syc/lib/`,
  они качались с `cdn.jsdelivr.net/npm/three@0.128.0/examples/js/...` и в архив не попали.
- **№ 8** (`src/mult/`) — Canvas 2D, «мультипликационные чернила»: контуры дрожат 9 раз в секунду
  (эффект boil), плоская заливка, шрифты Chewy и Neucha. Сборка: `python build.py`.

Общий приём во всех сборках: `head.html` плюс склеенные `*.js` в один HTML, картинки вшиваются
в base64 питоновским скриптом.

## 8. На чём остановились: текстуры из карт CS 1.6

Последняя идея владельца: **не рисовать текстуры руками, а взять их из карт CS 1.6**, которые
повторяют хрущёвку и подобные места.

Что нашлось:

- категория [«Типичная Россия»](https://all-cs.ru/cs16/maps/typical-russia) — 28 карт;
- [kz_plop](https://cstake.ru/maps/kz-maps/214-karta-kz_plop-dlja-cs-16.html) — паркур по квартире;
- [de_rats — кухня](https://cstake.ru/maps/de-maps/147-karta-de_rats-dlja-cs-16.html);
- [серия RF](https://steamcommunity.com/sharedfiles/filedetails/?id=3552719214) — карты по реальным
  местам с фототекстурами;
- GameBanana: [de_russka](https://gamebanana.com/mods/84906),
  [123_kommunarov_yelets](https://gamebanana.com/mods/97445);
- сборники карт: [ALL-CS.net.ru](https://all-cs.net.ru/load/maps_for_cs/sborniki_kart/84-1-2).

План, который обсуждался:

1. скачать `.bsp` (и `.wad`, если текстуры лежат снаружи);
2. скриптом распарсить текстуры (GoldSrc BSP v30 / WAD3: miptex с 8-битной палитрой) в PNG;
3. дальше либо **натянуть текстуры** на нашу геометрию, либо **загрузить саму карту** в браузер
   вместе с её запечённым светом (лайтмапами), поставить камеру у стола и посадить внутрь
   персонажей, кота, ник и Дверку. Второй вариант точнее попадает в вайб.

**Открытые вопросы для следующей сессии:**

- как называется карта с того скриншота, где на столе кастрюля оливье (если вспомнится —
  это идеальный кандидат);
- если нет, выбрать 3–4 карты из «Типичной России» и серии RF и показать;
- честная оговорка: CS сам полигональный. Фототекстуры и лайтмапы делают картинку тёплой,
  но полигоны не исчезнут.

## 9. Как продолжить с другого компьютера

1. Закоммитить и запушить репозиторий:

   ```
   git add concepts
   git commit -m "Add dverka.sk concept archive"
   git push
   ```

2. На другом компьютере склонировать репозиторий и дать новой сессии такой промпт:

   > Прочитай `concepts/HANDOFF.md`. Продолжаем работу над сайтом-визиткой dverka.sk
   > с того места, где остановились: текстуры и карты CS 1.6.

   `~/.claude/projects/C--Users-Admin-IdeaProjects-DverkaSK/memory/`. Их содержание
